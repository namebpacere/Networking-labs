### The Problem
A company may decide to move some of its applications, databases, or shared resources to the cloud. These resources need to be accessible from the company's local network, but they should not be directly exposed to the public Internet.

To solve this problem, the company can establish a site-to-site VPN between its local network and the cloud network. The VPN creates a secure and encrypted tunnel over the Internet, allowing users to access cloud resources as if they were part of a connected remote network.

This provides secure connectivity, controlled access, and protection of data in transit, while allowing the company to keep its cloud resources private.


This same problem (securely connecting an on-premise network to a private cloud subnet) is one of the most common patterns in enterprise networking: branch offices reaching centralized cloud resources, hybrid cloud migrations, multi-region architectures.
